# Parallel QuickHull — построение выпуклой оболочки

Параллельная реализация алгоритма **QuickHull** для построения выпуклой 
оболочки множества точек на плоскости. Проект сравнивает последовательную 
и параллельную версии алгоритма с использованием пула потоков.

## Задача

Дано множество точек на плоскости. Требуется построить **выпуклую 
оболочку** — наименьшее выпуклое множество, содержащее все точки.

**Цель**: применить пул потоков для ускорения алгоритма QuickHull
и сравнить результат с последовательной версией.

## Алгоритм работы QuickHull

Алгоритм основан на рекурсивном подходе и работает по принципу 
«разделяй и властвуй»:

1. Находятся точки с **минимальной и максимальной координатой X** — 
   они гарантированно принадлежат оболочке.
2. Множество точек разделяется на левое и правое подмножества 
   относительно прямой, проходящей через эти точки.
3. Для каждого подмножества рекурсивно находится точка, 
   **максимально удалённая** от отрезка между крайними точками.
4. Найденная точка добавляется в оболочку, процесс повторяется 
   для образовавшихся подотрезков.

**Сложность:**
- Средний случай: `O(n log n)`
- Худший случай: `O(n²)` — например, все точки лежат на окружности

## Ресурс параллелизма

Рекурсивные вызовы для левого и правого подмножеств **независимы** 
и могут выполняться параллельно. Это позволяет эффективно использовать 
многоядерные процессоры.

## Запуск проекта

### Требования

Перед началом убедитесь, что установлено:

- **Компилятор C++** с поддержкой C++17 (g++ или clang++)
- **Python 3** — только для визуализации (необязательно)

Проверить компилятор:

```bash

g++ --version     # версия должна быть 9.0 или новее
```
Клонировать репозиторий:
```bash
git clone https://github.com/tanyasol/quickhull-multithreaded.git
cd quickhull-parallel
```
Компиляция проекта:
```bash
g++ -std=c++17 -pthread -O2 \
    src/Point.cpp \
    src/Error.cpp \
    src/QuickHullSolver.cpp \
    src/QuickHullSequential.cpp \
    src/QuickHullParallel.cpp \
    src/ThreadPool.cpp \
    src/Validator.cpp \
    src/Presenter.cpp \
    src/main.cpp \
    -Iinclude \
    -o quickhull
```
Запуск:
```bash
./quickhull          
```
